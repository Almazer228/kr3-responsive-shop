# Контрольная работа №3 — Responsive Shop

**Тема:** «Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта».

## Описание проекта

Учебный многостраничный интернет-магазин, созданный на HTML, CSS и JavaScript. Проект основан на HTML/CSS-версии предыдущей контрольной работы и адаптирован для мобильных устройств, планшетов и компьютеров.

В проекте используются собственные CSS-медиазапросы, Flexbox, CSS Grid и responsive images. Bootstrap не используется.

## Страницы проекта

- `index.html` — главная страница и популярные товары;
- `catalog.html` — каталог товаров и демонстрационный блок фильтров;
- `product.html` — описание товара и таблица характеристик;
- `order.html` — форма оформления заявки;
- `contacts.html` — контактная информация учебного проекта.

## Технологии

- HTML5;
- CSS3;
- Flexbox;
- CSS Grid;
- Media Queries;
- Responsive Images (`srcset`, `sizes`);
- JavaScript (DOM и обработчики событий);
- Git и GitHub.

## Адаптивная вёрстка

Используется подход Mobile First: базовые правила рассчитаны на узкий экран, а для более широких экранов применяются медиазапросы.

Контрольные ширины для проверки в DevTools:

| Устройство | Ширина |
|---|---:|
| Mobile S | 320 px |
| Mobile M | 375 px |
| Mobile L | 425 px |
| Tablet | 768 px |
| Laptop | 1024 px |
| Laptop L | 1440 px |

Адаптивные решения:

- навигация переносится на мобильных устройствах; на широких экранах пункты меню центрированы в шапке;
- карточки товаров располагаются в одну колонку на телефонах, в две — на планшетах и в три — на широких экранах;
- фильтры каталога располагаются над товарами на узких экранах и сбоку на широких;
- блок страницы товара меняет расположение с одной колонки на две;
- форма заявки использует одну колонку на телефоне и две на широком экране;
- таблица характеристик прокручивается внутри `.table-wrapper`;
- изображения используют `max-width: 100%`, `srcset` и `sizes`.

## Доступность (A11y)

В проекте предусмотрены:

- семантические элементы `header`, `nav`, `main`, `section`, `article`, `aside` и `footer`;
- ссылка пропуска к основному содержимому (`skip-link`);
- видимый фокус интерактивных элементов при навигации с клавиатуры;
- альтернативные описания изображений (`alt`);
- связанные подписи полей форм (`label` и `for`/`id`);
- указание текущей страницы через `aria-current="page"`;
- доступное название модального окна через `aria-labelledby`;
- возврат фокуса к кнопке открытия модального окна;
- подпись таблицы характеристик через `caption` и обозначение заголовков через `scope`;
- поддержка системной настройки уменьшения анимации.

## Формы и демонстрационная логика

JavaScript открывает и закрывает модальное окно, подставляет выбранный товар, возвращает фокус к кнопке открытия и показывает демонстрационное сообщение после корректного заполнения формы.

**Важно:** проект не подключён к серверу. Данные форм не сохраняются и не отправляются; сообщение об успешной проверке является демонстрационным. Фильтры каталога также представлены как интерфейс и не выполняют фактическую фильтрацию товаров.

## Проверка Lighthouse

Проверьте категорию **Accessibility** как минимум на страницах `index.html`, `catalog.html` и `order.html`. Рекомендуется выполнить проверки в Chrome DevTools и повторить аудит после исправления обнаруженных проблем.

Сохраните реальные отчёты в папку `lighthouse/`:

- `accessibility-index.html`;
- `accessibility-catalog.html`;
- `accessibility-order.html`.

Числовые результаты Lighthouse необходимо вписать сюда после фактического запуска аудита. Они не указаны заранее, чтобы не подменять реальную проверку выдуманными значениями.

## Запуск проекта

1. Откройте папку проекта в Visual Studio Code.
2. Запустите `index.html` через расширение Live Server.
3. Проверьте переходы между всеми пятью страницами.
4. Для проверки адаптивности откройте DevTools и используйте указанные выше ширины экрана.
5. Для проверки доступности используйте клавишу `Tab` и Lighthouse в Chrome DevTools.

# Lighthouse reports

Сюда нужно сохранить реальные HTML-отчёты Lighthouse для категорий Accessibility:

- `accessibility-index.html` — главная страница;
- `accessibility-catalog.html` — каталог;
- `accessibility-order.html` — форма заявки.

Как получить отчёт: откройте страницу через Live Server в Chrome, откройте DevTools → Lighthouse, выберите Accessibility, запустите аудит и экспортируйте отчёт в эту папку.

Не добавляйте вымышленные результаты. После проверки внесите фактические баллы и найденные проблемы в корневой `README.md`.
